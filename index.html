3. Métodos oficiais

Work Profile

Quando a consola oferece “Remove Work Profile only”, o perfil de trabalho pode ser removido sem factory reset.

Dispositivo ligado

O administrador pode enviar “Unenroll Device”. Se a política do Agent permitir, o próprio utilizador pode pedir o unenrollment/desinstalar o Agent.

Dispositivo desligado

O administrador pode gerar um Offline Unenrollment Code. No Agent: Settings → Offline Unenrollment → introduzir o código → End.

Totalmente gerido / KME

O unenrollment pode implicar factory reset. Em Android Enterprise, o administrador pode também ter de desassociar/remover o perfil do Knox Mobile Enrollment para evitar novo enrollment.

Diagnóstico local: nenhuma informação é enviada por este site. Os dados escolhidos ficam apenas no navegador enquanto a página estiver aberta.
